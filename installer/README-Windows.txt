DEWITT 1.0 by slapworx
======================

40 pad effects for live beat sets. 3 banks x 16 pads: each pad plays an effect
(hold or latch), a move, a sample or a beat. MIDI learn for pads and knobs.

Windows 10 / 11, 64-bit. VST3 and CLAP.


INSTALLING
----------
1. Close your DAW.
2. Double-click "Install Dewitt.exe".
3. If Windows shows a blue "Windows protected your PC" box, click
   "More info", then "Run anyway". (The installer isn't code-signed yet.)
4. Click Next, Install, Finish.
5. Open your DAW and let it find new plug-ins. Most do this on start-up.
   FL Studio: Options > Manage plugins > Find installed plugins.
6. Put Dewitt on a track or on the master. It shows up under slapworx.

Rather copy the files yourself? Everything is in the "manual install" folder:
  Dewitt.vst3  ->  C:\Program Files\Common Files\VST3
  Dewitt.clap  ->  C:\Program Files\Common Files\CLAP


WHERE THINGS ARE (after installing)
-----------------------------------
  VST3 plug-in:   C:\Program Files\Common Files\VST3\Dewitt.vst3
  CLAP plug-in:   C:\Program Files\Common Files\CLAP\Dewitt.clap
  Manual, MIDI pictures and this file:   C:\Program Files\slapworx\Dewitt
  Start menu:     slapworx > Dewitt user manual / Dewitt - How to Set Up MIDI


GETTING STARTED
---------------
1. Send your controller's MIDI to Dewitt. The How to Set Up MIDI pictures show
   how for FL Studio, Ableton Live, Logic, Studio One, Bitwig, Reaper and Cubase.
2. Click SET UP CONTROLLER in Dewitt and follow the steps.
3. The user manual explains every effect, move and set.


UNINSTALLING
------------
Windows Settings > Apps > Dewitt > Uninstall, or Start menu > slapworx >
Uninstall Dewitt. Your presets and settings are kept.
